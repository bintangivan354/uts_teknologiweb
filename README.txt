WEBSITE UTS TEKNOLOGI WEB — BINTANG IVANDER ALLVASTA

Isi folder:
- index.html : struktur + konten website
- style.css  : desain dan responsive layout
- script.js  : menu mobile + animasi scroll + tahun otomatis

Cara pakai:
1. Pastikan ketiga file berada dalam satu folder.
2. Buka index.html di browser.
3. Website sudah responsif untuk desktop dan mobile.
4. Untuk hosting gratis, folder dapat diunggah ke GitHub Pages, Netlify, atau Cloudflare Pages.
